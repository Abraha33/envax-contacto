# ENVAX — User Flow v1

## Entry
Sources: QR card, website, social networks, WhatsApp, direct link.

`Entry → Landing → Business name → Business type → Continue → Catalog`

No traditional account creation is required for the initial catalog experience.

## Catalog exploration
`Catalog cover → Index / exploration mode → Category or Brand → Family → Product list → Product detail → Variant`

Supporting actions:
- Search
- Filters
- Return to index
- Switch between category and brand exploration

## Product interest
Every relevant product can expose a lightweight action such as `+ Me interesa`.

`Product → Me interesa → Mi selección`

The customer may continue browsing after every addition.

## Mi selección
Possible actions:
- Review selected products
- Remove product
- Add more products
- Open product again
- Request quote / advisor help

## Advisor flow with selection
`Mi selección → Cotizar estos productos → Choose WhatsApp or Email → Confirm → Request sent → Short customer confirmation → Advisor handles request`

The confirmation should be brief:
- products of interest;
- message that an advisor will attend shortly;
- link back to the catalog.

## Advisor flow without selection
A customer must never be blocked from contacting ENVAX.

`Hablar con un asesor → Suggest selecting products → Select products OR continue without selection → Contact channel → Advisor`

## Return visit
Future/persistent behavior may restore `Mi selección` and customer context. Cross-device identity remains unresolved and should not be guessed.

## Future promotions
With explicit consent:
`Known customer → Relevant promotion → Browser/email/WhatsApp channel according to strategy → Deep link to catalog → Product interest → Mi selección → Advisor`

Push/PWA behavior is future scope and must account for browser/platform limitations.
