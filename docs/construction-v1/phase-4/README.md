# Phase 4 — Anonymous Identity + Favorites

## Objective
Let customers return to ENVAX, keep their business context, and manage multiple named favorite lists without forcing traditional registration.

Planned branch: `build/identity-favorites-v1`

Entry condition: `CATALOG UX PASS`.

## In scope
- anonymous account/profile creation;
- secure session cookie;
- business name/type persistence;
- anonymous recovery mechanism;
- cross-device recovery flow;
- named favorite lists;
- add/remove/move favorite items;
- ownership isolation;
- recovery/security rate limits;
- audit events for sensitive identity actions.

## Out of scope
- verified customer Portal;
- pedido submission;
- promotion targeting;
- ERP integration.

## Required outputs
A customer can create named lists such as Halloween or Cumpleaños, leave, return, and recover the same anonymous profile safely.

## Exit
Phase 4 ends at `IDENTITY FAVORITES PASS`.
